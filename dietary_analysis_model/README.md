# SiBC 식이분석 모델

작성: 오재호 과장 · 헬스커넥트(주) AI플랫폼본부 SiBC

푸드렌즈(FoodLens)에서 들어온 식사 기록 DB를 사용자별 식이분석이 가능한 데이터
테이블로 구축하고, 그 위에서 산출한 식이분석 결과를 사용자와 의료진에게 각각 제공하는
모델입니다. 의료진용 결과는 의료진이 원하는 가이드라인을 선택해 판정할 수 있도록
설계합니다.

현재 단계는 설계 확정 및 구현 착수 전입니다. 상세 배경, 기준 수치, 데이터 자산과
작업 규칙은 [docs/HANDOVER_20261014.md](docs/HANDOVER_20261014.md)를 기준으로 합니다.

## 목표

- 하루 식사가 아니라 일정 기간(예: 최근 28일)의 일상 식습관을 판정합니다.
- 판정마다 근거가 된 기관, 지침명, 기준 연도, 지표를 함께 기록합니다
  ("기준이 명시된 식이분석").
- 하나의 판정 결과를 두 가지 출력으로 제공합니다.
  - 의료진: 기준과 데이터 출처가 명시된 판정 리포트(의학적 판단의 근거 자료)
  - 사용자: 부족 및 과잉에 대한 주의와 안내(식이습관 변화 유도)

시스템은 근거를 제공할 뿐 진단이나 처방을 하지 않습니다. 의학적 판단의 주체는
의료진이며, 사용자 문구는 안내입니다. 판정은 섭취 수준의 평가이며 건강 상태의 진단이
아닙니다.

## 구성

### 1. 사용자별 식이분석 데이터 테이블

| 단계 | 내용 |
|---|---|
| 입력 | 푸드렌즈 식사 로그(음식 항목, 추정 분량, 끼니, 일시), 온보딩 응답(NQ-2021 18문항, 자주 먹는 음식), 보완 설문 응답 |
| 매핑 | 푸드렌즈 음식 DB, 국민건강영양조사 FFQ 112항목, 식품군 사이의 매핑 테이블. 매핑 불가 음식은 식품군 수준 폴백과 미매핑 로그 축적 |
| 집계 | 기간 내 항목별 섭취 빈도와 분량 집계, 1일 평균 일상섭취량 추정(파생 FFQ) |
| 완전성 | 기록 일수와 누락 끼니 기반 기록 완전성 지표. 판정 신뢰 수준과 표기에 사용 |

FFQ 설문을 그대로 이식하지 않고, FFQ가 묻던 음식별 빈도와 분량을 푸드렌즈 로그에서
산출합니다. 로그로 알 수 없는 사각지대(주류, 음료와 커피, 식이보충제, 조리 시 소금과
기름, 미기록 끼니와 외식)만 최소 설문으로 보완합니다.

### 2. 판정 엔진

- 결정론적 규칙 엔진으로 판정합니다. RAG와 생성 모델은 음식명 정규화, 출처 인용,
  교육 문구 보조에만 사용하며 수치 판정에는 사용하지 않습니다.
- 사용자 프로필(성별, 연령, 신장, 체중)로 기준값을 재계산합니다(EER 등).
- 판정은 5단계입니다: 부족, 약간부족, 적절, 약간과잉, 과잉.

### 3. 가이드라인 선택

| 구분 | 적용 방식 |
|---|---|
| 기본값 | 한국인 영양소 섭취기준(KDRIs 2025) |
| 질환 맥락 | 의료진(또는 사용자)이 명시적으로 선택한 경우에만 국내 임상학회 지침 적용. 예: 대한당뇨병학회 진료지침 2023, 한국지질·동맥경화학회 이상지질혈증 진료지침 5판, 대한비만학회 비만 진료지침 |
| 참고 병기 | WHO, 미국, 유럽, 중국 기준은 "참고"로 함께 표기 |

학회 간 기준 차이는 평균이나 최엄격값으로 합치지 않고 기준별로 나란히 제시합니다.
기준 테이블에는 기준값과 함께 기관, 지침명, 기준 연도, 출처 식별자를 저장해 개정에
대응합니다.

### 4. 출력

판정 레코드 필수 필드:

```text
nutrient, value, unit
guideline_org, guideline_name, guideline_year, criterion_type, criterion_value
judgement, reference_note
data_basis, record_days, completeness
```

평가 근거의 출처(설문 추정, 혼합, 기록 기반)와 기록 일수는 사용자와 의료진 모두에게
항상 표기합니다. 사용자 및 의료진 문구는 임상영양 전문가 검수를 거쳐 확정합니다.

## 디렉토리 구조

```text
dietary_analysis_model/
├── README.md
├── 00_Data/            # 입력 데이터 (git 제외)
├── 01_Results/         # 분석 결과 (git 제외)

    └── HANDOVER_20261014.md
```

구현 시 예정 모듈 구조(착수 시 조정 가능):

```text
standards/   # 판정 기준 테이블 (기관, 지침명, 연도, 지표, 값, 출처ID)
mapping/     # 푸드렌즈 DB, FFQ 112항목, 식품군 매핑 테이블과 미매핑 리포트
aggregate/   # 로그 기반 빈도와 분량 집계, 일상섭취량, 완전성 지표
judge/       # 결정론적 판정 엔진 (프로필 기준 재계산, 5단계 판정, 병기 생성)
survey/      # NQ-2021 점수화, 보완 설문, 적응형 확인 질문, 전환 가중
report/      # 판정 레코드 스키마, 의료진 및 사용자 출력 생성
validate/    # CAN-Pro 비교셋 대조, 기준선 검증 러너
tests/
```

착수 순서: standards 데이터화, 판정 엔진 코어와 단위 테스트, CAN-Pro 비교셋 파서와
대조 러너, 매핑과 집계, 설문과 전환, 리포트.

## 검증 기준

- 1차(엔진 정확성): 자체 입력한 CAN-Pro 비교 테스트셋(30명, 각 3일 식단)에 대해 영양소
  합산 오차와 판정 라벨 일치율을 대조합니다.
- 2차(파생 FFQ 타당도): FFQ 자체 타당도(식사기록 대비 상관 r=0.41)를 통과 기준선으로
  삼습니다. 기준선을 넘기 전에는 "FFQ 대체" 또는 "표준 도구와 동등" 같은 성능 표현을
  쓰지 않습니다.
- 합성 데이터나 smoke 결과를 실제 성능으로 보고하지 않습니다.

## 제한사항

1. 기록 누락 편향: 촬영하지 않은 음식은 로그에 없습니다. 보완 설문과 완전성 지표로
   보정하지만 완전히 제거할 수는 없습니다.
2. 적용 연령: FFQ 112항목은 만 19~64세 대상으로 설계되었습니다.
3. 분량 정합: FFQ 분량 3구간과 푸드렌즈 g 추정 사이의 환산 규칙이 아직 없습니다.
4. NQ-2021 사용: 서비스 탑재 전 식약처 주관부서 사전 협의와 출처 표기가 필요합니다.
5. 검증 전 성능 주장 불가.

## 보안 및 데이터 규칙

- 원본 사용자 식별자, 원시 식사 기록과 건강정보 row, `.env` 내용과 DB 접속정보는
  저장소에 올리지 않습니다. 집계 통계, pseudonymized key, 합성 fixture만 허용합니다.
- CAN-Pro 데이터의 대량 추출과 재사용은 금지합니다(구조 벤치마킹만 허용).
- 농진청 국가표준식품성분표의 상용 서비스 사용 라이선스는 [확인 필요]입니다.
