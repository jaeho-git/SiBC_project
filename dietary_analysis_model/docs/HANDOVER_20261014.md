## 1. 프로젝트 배경과 최종 목표

- **푸드렌즈(FoodLens)**: 사용자가 음식 사진을 업로드하면 DB 기반으로 음식을 판별해 영양정보를 기록하고, 오인식 시 사용자가 음식명을 입력하면 명칭 기반으로 DB 영양정보가 입력되는 시스템. 방법론상 "식사기록법의 자동화"이며, **푸드렌즈 자체는 전제이지 평가 대상이 아님** (푸드렌즈 현황에 대한 평가적 서술 금지).
- **최종 목표**: 사용자의 식사 기록을 "어떤 가이드라인 기준으로 무엇이 부족하고 무엇이 초과인지"의 판정으로 바꿔 — **의료진에게는 기준·연도·데이터 출처가 명시된 판정 리포트(의학적 판단의 근거 자료)**, **사용자에게는 부족·과잉에 대한 주의·안내(식이습관 변화 유도)** 를 제공.
- **절대 경계**: 시스템은 근거를 제공할 뿐 **진단·처방을 하지 않음**. 의학적 판단의 주체는 의료진, 사용자 문구는 "안내". 모든 모델은 연구·보조 목적(SiBC 공통 원칙). 이 경계는 제약이 아니라 의료 현장 채택의 조건으로 설계 전반에 명문화되어 있음.
- 조직 맥락: 보고 대상은 가이드라인 근거를 중시. 방향 보고 자료는 "SiBC 식이분석 시스템 발표자료 20260910(최종 19장)"으로 확정. 세부 실행은 팀 내 실무 담당자와 협의 체계. **RAG 연결 구현은 팀 내 RAG 담당 개발자 몫이고, 본인(오재호)은 판정 규칙 명세·판정 엔진 쪽을 담당** — 이번 Claude Code 작업의 범위가 이것.

## 2. 확정 방향 요약 (한 장짜리)

시스템은 세 요소로 구성되며, 앞 둘은 리서치로 확정 완료.

| 요소 | 내용 | 상태 |
|---|---|---|
| ① 기준 | KDRIs 2025(원문 대조 완료)를 기본값으로, 질환 맥락은 국내 임상학회 지침 명시 선택, 국외·중국은 "참고" 병기. 모든 판정에 기관·지침명·연도 표기 | 확정 (수치는 §4) |
| ② 데이터 | 하루가 아닌 "일상 식습관"을 판정. FFQ 설문을 이식하지 않고 **FFQ가 묻던 것(음식별 빈도·분량)을 푸드렌즈 로그에서 산출 = 파생 FFQ**. 사각지대만 최소 설문, 초기 공백은 온보딩(NQ-2021 + 자주 먹는 음식)으로 해소 | 방향 확정 (설계는 §5) |
| ③ 전달 | 하나의 판정 → 의료진 리포트(기준 명시) + 사용자 안내(전문가 검수 문구)의 양방향 산출 | 설계 방향 (§6) |

핵심 문장: **"기준이 명시된 식이분석"** — 판정마다 어떤 가이드라인의 어떤 수치를 근거로 했는지가 함께 간다. / **"쓰면 쓸수록 설문이 사라지고 기록이 말해주는 시스템."**

용어 구분(중요): **식이분석** = 음식 종류·빈도·식품군 구성·식행동 평가(NQ-2021이 여기 해당 — 질 점수·등급). **영양분석** = 섭취량에 영양성분을 연결한 에너지·영양소 계산과 기준 대비 판정(파생 FFQ + KDRIs가 여기 해당). **NQ 점수를 영양소 섭취량으로 환산하지 않는다** — 두 결과는 구분 제시, 상담에서 함께 해석.

## 3. 시스템 파이프라인 (구현 대상)

```
[입력] 푸드렌즈 식사 로그 (음식 항목·추정 분량·끼니·일시)
   │   + 온보딩 응답(NQ-2021 18문항, 자주 먹는 음식 10~15개)
   │   + 보완 설문 응답(사각지대 5~15문항, 적응형)
   ▼
[1. 매핑] 푸드렌즈 음식 DB ↔ 국건영 FFQ 112항목 ↔ 식품군 매핑 테이블
   ▼
[2. 집계] 로그에서 항목별 섭취 빈도(9구간 환산)·분량 집계 → 기간(예: 최근 28일) 일상섭취량 추정
   │       기록 완전성 지표(기록 일수·누락 끼니) 산출
   ▼
[3. 판정] 결정론적 규칙 엔진: 일상섭취량 × 사용자 프로필(성별·연령·신장·체중) 기반
   │       기준 재계산(EER 등) → 가이드라인 기준값 대비 5단계 판정
   │       (부족/약간부족/적절/약간과잉/과잉 — CAN-Pro 실사로 실증된 형식)
   ▼
[4. 출력] 판정 레코드(기준 추적 필드 포함) → 의료진 리포트 / 사용자 안내 문구(전문가 검수 템플릿)
```

- 수치 판정은 **반드시 결정론적 규칙 엔진**. RAG·생성 모델은 음식명 정규화·매핑 보조, 근거·출처 인용, 교육 문구 보조에만 사용 — 판정을 검색·생성에 맡기지 않는다 (RAG 연결은 별도 담당자 구현).
- 콜드스타트 전환: 0~2주 온보딩 설문 중심("가입 설문 기반 초기 추정입니다" 표기) → 2~4주 설문+로그 혼합(가중치를 로그로 이동, 불일치는 확인 질문) → 4주 이후 로그 중심 파생 FFQ("최근 28일 기록 기반입니다" 표기). 구간 주 수는 예시이며 개인내 변이 문헌 근거로 설계 시 확정. **평가 근거의 출처(설문 추정/기록 기반·며칠)를 사용자·의료진 모두에게 항상 표기.**

## 4. 판정 기준 — 확정 수치 (규칙 테이블 원천)

전부 원문 대조·공식 출처 확인 완료. 규칙 테이블에는 **기준값과 함께 기관·지침명·기준 연도·출처 식별자를 저장**할 것 (개정 대응 — 2025년 말 KDRIs 개정을 리서치 중 실제로 겪음).

### 4-1. 기본값 — KDRIs 2025 (보건복지부·한국영양학회, 2025-12-31 발표, 발간등록번호 11-1352000-100416-13)
- 에너지적정비율(AMDR, 성인): 탄수화물 50~65 / 단백질 10~20 / 지방 15~30 %E (2020판 탄 55~65·단 7~20에서 조정됨)
- 포화지방산 7%E 미만(3~18세는 8%), 트랜스지방 1%E 미만, 콜레스테롤 300 mg/일 미만 권고(19세+)
- 당류(2025 변경): **총당류 20%E 이내 제한 + 첨가당 10%E 이내 제한** — 서로 다른 항목. 가당음료 최소화
- 나트륨: **충분섭취량(AI) 1,500 mg과 만성질환위험감소섭취량(CDRR) 2,300 mg은 서로 다른 지표 — 판정 기준은 CDRR 2,300 mg** (65~74세 1,900 / 75+ 1,800). CAN-Pro 실사에서 판정표는 AI, 컨설트 문구는 CDRR을 쓰는 이원 사용이 관찰됨 — 우리는 CDRR로 통일하되 지표명을 명시
- 식이섬유 충분섭취량: 남 30 / 여 20 g (50세+ 여 25)
- EER(성인 참고): 남 1,900~2,600 / 여 1,500~2,000 kcal — 프로필별 재계산 대상
- 배포: 한국영양학회 kns.or.kr 자료실. 해설 논문 DOI 10.4163/jnh.2026.59.2.93, 10.4163/jnh.2026.59.2.148

### 4-2. 국내 임상학회 (질환 맥락 — 명시 선택 시에만 적용)
- 대한당뇨병학회 진료지침 2023 (DOI 10.4093/jkd.2023.24.3.120): **다량영양소 비율을 정하지 않는 개별화가 공식 입장**. 유일한 수치 권고는 과체중·비만 시 5% 이상 체중 감량. 구판(2013~2015 계열)의 탄수화물 50~60%·콜레스테롤 200mg 등은 현행판이 폐기한 접근 — 인용 시 반드시 "구판" 명시. **임의로 수치를 부여하지 말 것**
- 한국지질·동맥경화학회 이상지질혈증 진료지침 5판(2022, lipid.or.kr): 총지방 30%E 이내 · 포화 7%E 이내 · 콜레스테롤 300 mg/일 미만
- 대한비만학회 비만 진료지침: BMI 분류 18.5 / 23 / 25 / 30 / 35 구간
- 질병관리청 국가건강정보포털: 고혈압 저염식 권고 (대한의학회 소금 6g은 원문 미확정으로 **삭제·사용 금지**)

### 4-3. 국외 참고 (기본값 아님 — "참고" 표기로 병기, 계보 근거)
- WHO: 나트륨 2,000 mg 미만(강력 권고, 2012, ISBN 978-92-4-150483-6) / 유리당 10%E 미만·조건부 5%(2015, ISBN 978-92-4-154902-8)
- 미국: DGA 2020-2025·2025-2030(2026-01-07 발표) 포화 10%E 미만·나트륨 2,300 / AHA·ACC 2018 포화 5~6%(DOI 10.1161/CIR.0000000000000625, PMID 30586774) / ADA 개별화 원칙
- 유럽 ESC/EAS 2019: 포화 10%E(고콜레스테롤혈증 7%) (DOI 10.1093/eurheartj/ehz455)
- 중국(팀장 공유 자료로 확정): 거민선식지남 2022 — 소금 5 g·첨가당 50 g(가급적 25 g)·트랜스 2 g·알코올 15 g / 국가위생건강위 질환별 식양지남(고혈압·당뇨병·고지혈증 2023년판, 골다공증·근감소증·뇌졸중 2026년판 등 9종) — 고지혈증 지방 20~25%E·콜레스테롤 300(고콜레스테롤혈증 200) mg·식이섬유 25~40 g(수용성 7~13 g)·탄수화물 50~60%E, 당뇨 탄수화물 1일 200~300 g 정량, 조리유 25 g 이하, **중국 자체 BMI 과체중 24·비만 28(한국 23/25와 상이)** / WS/T 578 참고섭취량·WS/T 476 영양 표준용어
- 계보: KDRIs 지방 비율은 AHA/ACC, 첨가당은 WHO 권고 토대 — "국내 기준 적용 = 국제 정합"의 근거

### 4-4. 병기·적용 원칙 5 (판정 규칙 설계의 뼈대)
① 판정 기본값은 KDRIs 2025 ② 질환 맥락은 학회 지침을 명시 선택(사용자/의료진이 선택한 맥락일 때만) ③ 국외·중국은 "참고" 표기로 병기 ④ 모든 판정에 기관·지침명·연도 표시 ⑤ 검증 전 "표준 도구와 동등" 등 성능 표현 금지.
협회 간 차이는 평균·최엄격값으로 덮어쓰지 않고 병기: "A 기준으로 X, B 기준으로 Y"를 말할 수 있어야 함 (예: 포화지방 국내 7 / 미국 5~6 / 유럽 10).

## 5. 데이터 설계 — 파생 FFQ

### 5-1. 근거 사실 (원문 확인 완료)
- 국건영 영양조사 = 24시간 회상법(전 연령, 1일) + **식품섭취빈도조사 FFQ(만 19~64세)** + 식생활조사(식행태·보충제 설문)의 3체계
- **FFQ 112항목** 구성: 밥류 5 · 면·만두 6 · 빵·떡 8 · 국·찌개 12 · 콩/달걀/고기/생선 23 · 채소/해조/서류 27 · 우유류 4 · 과일 13 · 음료 5 · 과자 6 · 주류 3 — × 빈도 9구간 × 분량 3구간(소/중/대)
- 개발 근거: 24시간 회상 실측(2007~2009)에서 에너지·14영양소 **기여율 87%** 항목 추출 — 개발 논문: 한국영양학회지 2013;46(2):186, DOI 10.4163/kjn.2013.46.2.186. 실측→빈도 체계의 역방향에 학술 선례가 있다는 뜻
- FFQ 타당도: 식사기록 대비 상관 r=0.41(신뢰도 0.55) — **파생 FFQ 검증의 통과 기준선**
- 개인내 변이: 영양 섭취 변이의 60~85%가 개인내(날짜 간) 변이 — 하루 판정이 불안정한 근거, 전환 구간 설계의 근거
- 조사표 입수: 공식 누리집 knhanes.kdca.go.kr "조사표" 메뉴 공개(원시자료는 회원가입·이용지침). **주의**: FFQ는 모든 기수 시행이 아님 — "식품섭취빈도조사표" 명칭의 별도 문서를 시행 기수(제6기 2013~2015 전후)에서 찾아야 함, 정확한 시행 기수 범위 [확인 필요]. 2025년 "식생활조사표(성인)"는 FFQ가 아니라 식행태 설문(아침식사·외식·보충제·영양표시)이며 — 보완 설문 설계의 참고 원본으로 확보됨

### 5-2. 파생 FFQ 산출 설계
- 매핑 테이블: 푸드렌즈 음식 DB ↔ FFQ 112항목 ↔ 식품군. 1:N/N:1 허용, 매핑 불가 음식은 식품군 수준 폴백 + 미매핑 로그 축적
- 집계: 기간 내 항목별 섭취 횟수 → FFQ 빈도 9구간 환산(또는 연속 빈도 그대로 사용 — 설계 결정 사항), 분량은 푸드렌즈 추정량 사용. **분량 정합(FFQ 소/중/대 ↔ 푸드렌즈 g 추정)의 환산 규칙은 미설계 — 구현 과제**
- 일상섭취량: 항목별 (빈도 × 1회 분량 × 영양성분) 합산 → 1일 평균 환산. 영양성분 원천은 §7 공공 DB
- 기록 완전성: 기간 내 기록 일수·끼니 누락을 지표화(예: 완전성 상/중/하) — 판정 신뢰 수준과 리포트 표기("기록 24일")에 사용. 완전성이 낮으면 설문 기반 표기 유지

### 5-3. 보완 설문 (사각지대 한정)
- 원칙: **"로그에서 계산되는 문항은 묻지 않는다"** — 사용자당 5~15문항, 적응형
- 사각지대 목록과 사유: 주류(식사 외 자리·촬영 회피) / 음료·커피 습관(수시 섭취로 누락) / 식이보충제(음식이 아니라 촬영 대상 아님) / 조리 시 소금·기름(완성 사진에서 식별 불가) / 미기록 끼니·외식 빈도(사진 밖 정보)
- 선례: 국건영도 식품섭취조사와 별도로 식생활조사를 설문으로 둠 — 같은 구조. 확보된 2025 식생활조사표(성인)가 문항 설계 참고 원본
- 적응형: 설문 응답과 실제 로그가 불일치하는 항목은 확인 질문으로 동적 보강

### 5-4. 온보딩 (콜드스타트)
- **NQ-2021 (영양지수, 18문항)**: 식약처 지원·한국영양학회 개발. 개정 논문 J Nutr Health 2022;55(2):278-295, DOI 10.4163/jnh.2022.55.2.278 (원판 2018;51(4):340, DOI 10.4163/jnh.2018.51.4.340). 전국 6개 광역시 층화추출 1,000명 타당도 검증. 구성: 균형 8(전곡·생선·콩·견과·채소 반찬·과일·우유유제품·아침식사) + 절제 6(적색육·가공육·맵고 짠 국물·패스트푸드·기름진 빵과자·과식폭식) + 실천 4(고위험음주·건강 식생활 노력·영양표시 확인·손 씻기). 항목별 가중치로 영역 점수·등급 산출 → 첫날 "식사의 질" 등급 제공
  - 입수: 식품안전나라(various.foodsafetykorea.go.kr/nq)·한국영양학회 공개. **사용 요건(확인 완료): 출처 표기 + 식약처 주관부서(식품의약품안전평가원 영양기능연구과) 사전 협의 — 서비스 탑재 전 필수 절차**
  - NQ는 CAN-Pro 등재 독점 지수 산식과 별개로 공개 산출자료 기준으로 구현할 것
- 자주 먹는 음식 선택 10~15개: 개인 습관 프로필 + 개인 음식 사전 생성(이후 인식 정확도 향상 부수 효과)

## 8. 검증 설계

- **통과 기준선: FFQ 자체 타당도(식사기록 대비 상관 0.41)** — 파생 FFQ 추정치가 이를 넘으면 "설문 없이 설문 이상"을 근거를 갖고 주장 가능. 넘기 전에는 "FFQ 대체·이상" 표현 금지
- 1차 검증(엔진 정확성): 캔프로 비교 테스트셋(30명×3일) — 동일 식단에 대해 우리 영양성분 합산·판정과 CAN-Pro 산출 대조(영양소 합산 오차, 판정 라벨 일치율). CAN-Pro 산출의 대량 재사용이 아니라 자체 입력 사례의 결과 대조임에 유의
- 2차 검증(파생 FFQ 타당도): 로그 기반 일상섭취량 vs 기준 방법 — 설계 미착수, 실행 계획 과제
- 합성·스모크 결과를 실제 성능으로 해석·보고하지 않는다. 실행하지 않은 테스트를 성공했다고 보고하지 않는다

## 9. 제한사항 (확정 5)

① 기록 누락 편향 — 찍지 않은 음식은 로그에 없음. 적응형 미니 설문·완전성 지표로 보정, 완전 제거 불가(구조적 한계) ② 적용 연령 — FFQ 112항목은 만 19~64세 설계, 고령·소아는 생애주기 도구(NQ-E·NQ-A 등) 별도 검토 ③ 분량 정합 — FFQ 3구간 ↔ 푸드렌즈 분량 추정 환산 규칙 부재(구현 과제) ④ NQ 사용 절차 — 탑재 전 식약처 주관부서 사전 협의 + 출처 표기 ⑤ 검증 전 성능 주장 불가 — 기준선 0.41

## 10. 구현 제안 (Claude Code 착수 가이드)

권장 모듈 구조(제안 — 착수 시 조정 가능):
```
dietary_analysis_model/
  standards/        # 판정 기준 테이블 (기관·지침명·연도·지표·값·출처ID — §4를 데이터화)
  mapping/          # 푸드렌즈DB-FFQ112-식품군 매핑 테이블·로더·미매핑 리포트
  aggregate/        # 로그→빈도·분량 집계, 일상섭취량, 완전성 지표
  judge/            # 결정론적 판정 엔진 (프로필 기준 재계산, 5단계 판정, 병기 생성)
  survey/           # NQ-2021 점수화, 보완 설문·적응형 확인 질문, 전환 가중
  report/           # 판정 레코드 스키마, 의료진/사용자 출력 생성(문구는 템플릿+검수 전제)
  validate/         # 캔프로 비교셋 대조, 기준선 검증 러너
  tests/
```
착수 순서 제안: ① standards 데이터화(이 문서 §4 그대로, 기준 연도 필드 포함) → ② 판정 엔진 코어(프로필 재계산·5단계) + 단위 테스트 → ③ 캔프로 비교셋 파서(IntekeNutrient 레이아웃)·대조 러너 → ④ 매핑·집계 → ⑤ 설문·전환 → ⑥ 리포트.

**필수 요구 — 자가진단 하네스**: 문제를 보고만 하지 말고 "재현 → 원인 위치 특정 → 수정 → 테스트로 검증"의 자가 수정 루프를 갖출 것. 판정 엔진에는 기준 테이블 무결성 검사(값·단위·연도 누락), 경곗값 테스트(구간 경계), 회귀 테스트(캔프로 비교셋 스냅샷)를 포함.

## 13. 용어 최소 정리
