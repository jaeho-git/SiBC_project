## 3. 산출물

### 3.1 `data/knhanes_reference_dist.csv` — 칸별 가중 분포 (git 추적)

성별(M/F) × 연령대(19-29, 30-49, 50-64, 65-74, 75+) × BMI 구간(UNDER <18.5, NORMAL 18.5~22.9, PRE_OBESE 23~24.9, OBESE ≥25) × 영양소.
열: `n`, `weighted_mean`, `weighted_sd`, `p5 p10 p25 p50 p75 p90 p95`. 표본 30명 미만 칸은 제외해 39개 칸 × 20개 영양소 = 780행이다.
용도: 결과 값의 설득력 표현("같은 성·연령·체형 집단의 상위 n%")과 회귀 모형의 교차 확인.

정상 BMI의 하루 열량 중앙값(kcal): 여 19-29세 1,558, 30-49세 1,492, 50-64세 1,493, 65-74세 1,395, 75+세 1,253 / 남 19-29세 2,024, 30-49세 2,079, 50-64세 1,956, 65-74세 1,796, 75+세 1,625.

### 3.2 `data/knhanes_reference_model.json` — 회귀 표준화 계수 (git 추적)

영양소별로 가중 최소제곱 `log(섭취량) ~ 1 + 여성 + 연령 + 연령²/100 + 신장(cm) + 체중(kg) + 주말`을 적합했다.
칸을 나누지 않고 성·연령·키·체중을 연속으로 반영하므로 표본이 작은 칸 문제가 없다(설계 §3.3의 "회귀 표준화").

사용법:

```
expected_log = Σ coef_k · x_k          (x = [1, 여성, 연령, 연령²/100, 신장, 체중, 주말])
z            = (log(사용자 섭취량) − expected_log) / residual_sd
백분위       = Φ(z)
```

적합 결과(열량): n 16,106, 가중 R² 0.17, 잔차 SD 0.371(log). 나트륨 R² 0.13, 단백질 R² 0.15. R²가 낮은 것은 하루 회상 자료의 개인 내 변동이 크기 때문이며(§5 한계), 계수 부호는 기대와 일치한다(여성 −, 신장·체중 +, 연령 역U자).

## 4. 시스템에서의 사용

- 습관 층(설계 §3.2 5단계)의 창 평균 섭취량에 §3.2 모형을 적용해 `집단 백분위`를 계산하고, 재표집 신뢰구간은 개인 창 안의 일별 값으로 구한다.
- 참조 버전을 결과 값 레코드에 남긴다. 참조를 갱신(연도 추가)하면 버전을 올리고 판정 변동률을 평가한다(설계 §5.3).
- 맥락 층은 단독으로 판정하지 않는다. 기준·방향 층이 "줄임"인데 백분위가 하위권이면 데이터 오류 신호로만 쓴다.

## 5. 한계와 후속

- **단일일 분포 대 다일 평균.** 참조는 하루 24시간 회상이라 잔차 SD에 개인 내(날마다) 변동이 포함되어 있다. 사용자의 7일 이상 평균을 이 분포에 대면 변동이 작은 값을 넓은 분포에 비교하는 셈이라 **백분위가 중앙으로 쏠린다**(보수적). 개인 내/개인 간 분산을 분리하는 보정(NCI 방법 등)은 후속 과제이며, 그 전까지 백분위는 순위 참고용으로만 쓴다.
- 주말 표본이 5%라 주말 계수는 불안정하다. 사용자 창 평균에는 주말이 2/7 포함되므로 `weekend = 2/7`을 넣어 쓰는 것을 기본으로 한다.
- 80세 이상은 80으로 상한 처리되어 있다.
- 트랜스지방은 참조가 없다. `N_DUSUAL`(평소보다 많이/적게 먹은 날)은 추출만 하고 아직 쓰지 않는다. 평소 식사량과 다른 날을 제외하는 선정 기준은 평가 후 결정한다.
- 재생성: `uv sync --extra ref` 후 문서 상단 명령을 실행한다.
