# 식이분석 시스템 설계 — 보조 설문과 기록 우선 구조 (2026-10-20)

근거: SiBC 식이분석 시스템 발표자료(2026-09-28), 성인(만 19~64세) 영양지수 설문지(NQ-2021, 18문항 + 참고 2문항 + 일반사항 4),
국민건강영양조사 식품섭취빈도조사 체계(11개 식품군 112항목, 빈도 9구간, 1회 분량 3구간; Kim DW 외 2013, DOI 10.4163/kjn.2013.46.2.186).

> **보조 문서 (2026-10-26 표시).** 사용자·의료진 전달 방식(그림 A/B/C)과 끼니 고정 배분 판정은 [system_design_20261022.md](system_design_20261022.md)(정리본)로
> 대체되었다. 이 문서의 설문 최소화·근거 수준(L0~L3)·보완 문항(F1~F8) 설계는 그대로 유효하며, 설계 기준 문서의 완전성 보완(§3.5)과 함께 읽는다.

방향 결정: 설문은 **보조**다. 기록(푸드렌즈)만으로 완성된 결과가 나오고, 설문에 답한 사용자는 더 정밀한 결과를 받는다.

## 1. 설문의 역할 재정의

| 구분 | 발표자료(2026-09) | 수정 방향 |
|---|---|---|
| 온보딩 | NQ-2021 18문항 + 자주 먹는 음식 10~15개 (약 5분, 첫날) | 일반사항(D1~D4)은 `user_master`에서 가져옴. 자주 먹는 음식 선택만 첫날 **권유**(건너뛰기 가능). NQ 문항은 첫날 받지 않음 |
| 설문 → 로그 전환 | 0~2주 설문 중심, 2~4주 혼합, 4주 이후 로그 중심 | 첫날부터 로그 중심. 설문이 없으면 기본값·본인 이력으로 보정 |

| 최소 설문 보완(사각지대) | 주류·음료·보충제·조리 소금/기름·미기록 끼니·외식 | 유지하되 **상황이 생길 때 1문항씩**, 기본값 있음 |

## 2. NQ-2021 문항별 처리: 로그에서 산출 가능한가

NQ-2021 평가문항 18개(균형 8 · 절제 6 · 실천 4)와 참고 2개를 "로그에서 자동 산출 가능 / 설문 필요"로 나눈다.
로그 산출에는 푸드렌즈 음식 → 국건영 식품군 매핑(파생 FFQ 매핑표)이 필요하다.

- 따라서 NQ 등급은 L1 사용자에게도 **"로그 기반 추정 NQ"** 로 제공할 수 있다. 단, 공식 NQ 점수(식약처·한국영양학회 산식)는 설문 응답으로만 계산하고, 로그 기반 값은 "추정"으로 구분 표기한다(발표자료 슬라이드 9·14 원칙).

## 3. 추가 문항: 자주 섭취하는 음식 (파생 FFQ 보조)

국건영 FFQ 112항목을 그대로 묻지 않고, **11개 식품군 구조**를 빌려 "자주 먹는 음식을 고르는" 선택형으로 바꾼다.
목적은 두 가지다: ① 개인 음식 사전(푸드렌즈 인식 정확도 향상), ② 사진에 잘 안 찍히는 식품군의 사각지대 확인.
모든 문항은 건너뛸 수 있고, 건너뛰면 기본값으로 처리된다.

### 3.1 F1. 자주 먹는 음식 고르기 (온보딩 권유, 1~2분)

> "평소 **일주일에 2번 이상** 먹는 음식을 골라 주세요. (여러 개 선택, 없으면 건너뛰기)"

식품군 탭 11개 아래에 대표 음식 카드를 보여주고 탭으로 고른다. 식품군과 예시는 국건영 FFQ의 11개 군 구성을 따른다
(세부 112항목명은 질병관리청 조사표와 대조해 확정).

| 식품군 (국건영 FFQ) | 카드 예시 | 영양 판정에 쓰는 곳 |
|---|---|---|
| 밥류 | 흰쌀밥, 잡곡밥·현미밥, 볶음밥, 김밥, 덮밥류 | 탄수화물, 전곡(NQ 7) |
| 면·만두류 | 라면, 칼국수·국수, 짜장면·짬뽕, 파스타, 만두 | 나트륨, 국물음식(NQ 10) |
| 빵·떡류 | 식빵·토스트, 크림빵·도넛, 샌드위치·햄버거빵, 떡 | 당류, 기름진 빵(NQ 8) |
| 국·찌개류 | 된장찌개, 김치찌개, 미역국, 설렁탕·곰탕, 순두부, 부대찌개 | 나트륨 |
| 콩·달걀·고기·생선류 | 두부·콩, 달걀, 닭고기, 삼겹살·돼지고기, 소고기, 햄·소시지, 생선구이, 회, 오징어·조개 | 단백질, 포화지방, 가공육(NQ 11·12), 생선(NQ 4), 콩(NQ 5) |
| 채소·해조·서류 | 배추김치, 나물류, 샐러드·생채소, 김·미역, 감자·고구마, 버섯 | 식이섬유, 칼륨, 채소 가짓수(NQ 1) |
| 우유류 | 우유, 요구르트, 치즈, 두유 | 칼슘 (NQ 3) |
| 과일류 | 사과, 귤·오렌지, 바나나, 딸기·베리, 수박·참외, 포도 | 비타민 C, 당류 (NQ 2) |
| 음료류 | 커피(블랙/믹스), 탄산음료, 과일주스, 이온음료, 차 | 당류 (NQ 19) |
| 과자류 | 과자·스낵, 초콜릿·사탕, 아이스크림, 견과류 | 당류, 지방 (NQ 6·8) |
| 주류 | 소주, 맥주, 와인·막걸리 | 에너지, 음주(NQ 18) |

- 저장: 사용자 × 음식 코드 × 선택일. 푸드렌즈 인식 후보 가중치와, 선택된 식품군의 로그 공백 감지(아래 3.2)에 쓴다.
- 건너뛰면: 개인 사전 없음. 분석 결과에는 영향 없음(인식 정확도만 기본 수준).

### 3.2 F2~F6. 사각지대 확인 질문 (상황 발생 시 1문항씩, 하루 최대 1개)

사진으로 알 수 없는 항목만 묻는다. 각 문항은 **트리거 조건**이 충족될 때만 뜨고, 답은 유효기간 동안 재사용한다.

| 코드 | 문항 | 보기 | 트리거 | 기본값(미응답) | 영양 판정 반영 | 유효기간 |
|---|---|---|---|---|---|---|
| F2 | "국·찌개·탕 국물은 보통 어느 정도 드세요?" | 거의 안 먹음 / 반 정도 / 다 먹음 | 국물음식이 주 3회 이상 기록 | 반 정도 | 국물음식 나트륨 계수 0.5 / 0.75 / 1.0 | 180일 |
| F3 | "요즘 영양제(비타민·미네랄 등)를 드시나요?" | 안 먹음 / 종합비타민 / 기타(선택) | 분석 시작 7일 후 1회 | 안 먹음 | 해당 미량영양소에 "보충제 미반영" 표시 → 응답 시 제외 또는 가산 | 180일 |

| F5 | "가당음료(탄산·믹스커피·주스 등)는 얼마나 자주 드세요?" (NQ 19 보기) | 2주 1회 이하 / 주 1~3회 / 주 4~6회 / 하루 1~2회 / 하루 3회 이상 | 음료 기록이 14일간 0건 | 주 1~3회 | 당류·에너지 추정 가산, NQ 19 | 180일 |
| F6 | "저녁(또는 해당 끼니)은 보통 어떻게 하세요?" | 안 먹어요 / 먹지만 기록 안 해요 / 가끔 먹어요 | 같은 끼니 미기록(결식 표시 없음)이 7일 중 4일 이상 | 먹지만 기록 안 함 | "안 먹음" → 결식 처리, "기록 안 함" → 본인 끼니 평균으로 보정(③) | 90일 |
| F7 | "외식·배달은 일주일에 몇 번쯤 하세요?" | 거의 안 함 / 1~2회 / 3~5회 / 거의 매일 | 분석 시작 14일 후 1회 | 1~2회 | 나트륨·지방 추정 보정 계수, 상담 문구 | 180일 |

### 3.3 F8. NQ 행동 문항 (선택, "식사의 질 점수" 희망자만)

로그로 산출할 수 없는 NQ 4문항(15 노력, 16 영양표시, 17 손 씻기, 20 운동)과 부분 산출 문항(6·8·14·18·19)을 **한 번에 묻는 짧은 설문(약 1분)** 으로 묶어, 기록 7일 뒤 "식사의 질 점수(공식 NQ)도 볼까요?"로 제안한다.
응답자는 공식 NQ 점수·등급(L3), 미응답자는 로그 기반 추정 NQ(L1·L2)를 받는다.

## 4. 수정된 시스템 구조

```
푸드렌즈 기록 ──▶ ① 끼니·하루 집계 ──▶ 공백 보정 ──▶ ② 영양소 판정 (KDRIs 등) ──▶ 의료진 리포트 / 사용자 안내
   (실측)            (현재 구조)        ▲      ▲        ③ 7~180일 패턴              + 근거 수준·추정 항목 표시
                                        │      │
                       본인 끼니 이력(③) ┘      └ 확인된 습관(F2~F7 답변, 없으면 기본값)
                                                  자주 먹는 음식(F1) → 인식 정확도
파생 FFQ 매핑표 (푸드렌즈 음식 → 국건영 11식품군) ──▶ 로그 기반 추정 NQ (13문항 자동) / 공식 NQ (F8 응답 시)
```

### 4.1 근거 수준 (evidence level)

| 수준 | 조건 | 제공 결과 |
|---|---|---|
| L0 | 기록 3일 미만 | 수치 판정 없음. F1 권유 |
| L1 기록 기반 | 기록 3일 이상, 설문 없음 | 영양소 23개 판정 전체 + 로그 기반 추정 NQ. 사각지대는 기본값, "추정" 표시 |
| L2 기록+확인 | L1 + F2~F7 일부 응답 | 응답 항목의 기본값을 개인값으로 교체 (나트륨·당류·에너지 정밀도 상승) |
| L3 기록+프로필 | L2 + F1 + F8 | 공식 NQ 점수·등급, 개인 음식 사전 |

### 4.2 판정 입력값 완성 규칙 (설문 유무와 무관하게 실행)

1. **미기록 끼니**: `day_record_status = PARTIAL`이고 결식 기록이 없으면 F6 답변 → 없으면 본인 최근 30일 해당 끼니 평균(③)으로 채우고 `imputed` 표시. 이력이 없으면 채우지 않고 "과소 추정 가능" 표시.
2. **조리 소금**: 국물음식 나트륨에 F2 계수 적용. 기본 0.75.
3. **음료·주류**: 로그에 있으면 로그 우선. 14일간 0건이면 F4·F5 답변 또는 기본값으로 주간 추정량 가산, `estimated` 표시.
4. **보충제**: F3 응답 전에는 미량영양소 판정에 "보충제 미반영" 문구.
5. **외식**: 음식명·태그에서 외식 추정, F7 답변으로 보정.

### 4.3 데이터 모델 추가 (현재 3테이블 위에)

| 항목 | 위치 | 내용 |
