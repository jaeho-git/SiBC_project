# SiBC 웨어러블 기반 건강검진 예측 프로젝트

## 1. 이 프로젝트는 무엇인가

SiBC는 스마트워치·연결기기·라이프로그에서 지속적으로 쌓이는 데이터를 이용해, 건강검진 관련 수치 중 **웨어러블 정보로 의미 있게 추정 가능한 항목**의 최근 상태를 예측하려는 프로젝트다. 건강검진을 대체하거나 질병을 진단하려는 모델이 아니라, 검진 사이의 정보 공백을 줄이고 사용자의 변화를 탐색하기 위한 건강관리 지원 모델이다.

이 문서는 구현 방법이나 저장소 운영 방식을 지시하지 않는다. 다른 AI가 프로젝트의 목적과 의사결정 원칙을 오해하지 않도록 하는 최소한의 공통 맥락이다.

## 2. 왜 필요한가

건강검진은 보통 1년 단위 또는 그보다 긴 간격으로 기록된다. 반면 활동량, 수면, 심박수, 체성분, 혈압 등은 일상에서 반복 측정될 수 있다. 따라서 웨어러블의 장기 패턴을 잘 사용하면 다음과 같은 가치를 만들 수 있다.

- 건강검진 이력이 없는 사용자에게도, 데이터가 충분한 경우 일부 건강 관련 수치의 추정값을 제공한다.
- 과거 건강검진 이력이 있는 사용자에게는, 그 이후 누적된 웨어러블 데이터를 반영한 **최근 추정 상태**를 제공한다.
- 실제 검진값이 새로 들어오면 예측값과 비교하여 변화 추적·모델 검증·개인화에 활용한다.
- 예측 근거와 불확실성을 함께 제시하여, 사용자가 검진 또는 전문가 상담이 필요한 시점을 판단하는 보조 신호로 사용하게 한다.

## 3. 모델이 답하려는 질문

> “이 사용자의 예측 기준시점 이전 웨어러블 데이터만으로, 해당 시점의 건강검진 관련 수치를 얼마나 신뢰성 있게 추정할 수 있는가?”

중요한 원칙은 건강검진 유무로 사용자를 배제하지 않는 것이다. 과거 건강검진은 있을 수도 있고 없을 수도 있으며, 웨어러블 기반 예측이 주 목적이다.

| 사용자 상황 | 모델 입력 | 모델이 제공할 결과 |
|---|---|---|
| 건강검진 이력 없음 | 일정 기준을 충족한 웨어러블 데이터 | 예측 가능 항목의 추정값·신뢰도·예측 보류 사유 |
| 과거 건강검진 이력 있음 | 웨어러블 데이터, 필요 시 가장 최근 과거 검진값과 경과시간 | 최신 상태의 추정값 및 과거 실제값 대비 변화 |
| 반복 건강검진 이력 있음 | 이전 검진값과 두 검진 사이 웨어러블 데이터 | 다음 검진값 또는 변화량의 추정 및 검증 근거 |

## 4. 모델의 개념적 구조

모델은 특정 알고리즘 하나를 의미하지 않는다. 건강검진 항목마다 정보의 성격과 예측 가능성이 다르므로, 다음의 3개 계층으로 구성하는 것이 타당하다.

1. **개인별 웨어러블 상태 요약 계층**: 예측 기준시점 이전의 활동·수면·심박·체성분·식사·기분 등의 원시 기록을 기간별 평균, 변동성, 추세, 결측률, 측정 빈도로 요약한다.
2. **항목별 건강검진 예측 계층**: 공통 건강 상태와 항목별 관련 특징을 사용해 수치형 항목은 연속값, 범주형 항목은 위험군 확률을 추정한다. 과거 검진값이 있으면 이를 보조 입력으로 활용하되, 웨어러블만으로도 작동하는 모델을 별도로 유지한다.
3. **신뢰도·안전 계층**: 데이터 기간·일수·측정 품질·사용자와 학습 집단의 유사성에 따라 예측을 제공하거나 보류한다. 결과에는 점 추정값뿐 아니라 불확실성, 사용 근거, 예측 기준일을 표시한다.

즉, 동일 사용자의 과거 검진값을 단순 재표시하는 모델이 아니라, **웨어러블 변화로부터 최근 상태를 추정하고 불확실할 때는 예측하지 않는 모델**을 지향한다.

## 5. 건강검진 정답 데이터

학습·검증의 기준 건강검진 데이터는 아래 원천만 사용한다.

- 원천: `discovery.disc_medical_user_info.user_health_sn.health_info_data`
- 건강검진 측정 기준일: `health_info_data` 내부의 `measuredDt`
- `ins_dt`, `upd_dt`는 DB 적재·수정 시점일 수 있으므로 임상 측정일의 대체값으로 사용하지 않는다.

대표적으로 표준화 가능한 항목은 신장, 체중, BMI, 허리둘레, 수축기·이완기 혈압, 혈색소, 공복혈당, AST, ALT, γ-GTP, 총콜레스테롤, HDL, LDL, 중성지방, 크레아티닌, eGFR, 요단백 등이다. 기관별 표기와 단위가 다를 수 있으므로, 항목별 코드·단위·정상범위를 표준화한 뒤에만 정답값으로 사용해야 한다.

## 6. 사용 가능한 웨어러블·라이프로그 데이터

현재 사용 가능한 원천은 `discovery.disc_lifelog_user_*` 계열 16종이다. 일부 데이터는 상위 레코드의 SN을 통해 연결되므로, 테이블 이름만 보고 독립적인 사용자 단위 데이터로 간주하면 안 된다.

| 데이터 영역 | 현재 원천 | 건강검진 예측에서의 역할 |
|---|---|---|
| 사용자 기본정보 | `user_info` | 사용자 연결, 기기·기록 맥락 확인 |
| 활동·걸음 | `activity`, `step` | 활동량, 좌식성, 활동 강도·규칙성 |
| 운동·소비 열량 | `activity`, `calories` | 운동량·에너지 소비 추정 |
| 심박 | `heartrate` | 안정시 심박, 심박 변동·운동 반응의 보조 지표 |
| 혈압 | `bloodpressure` | 혈압 추정의 직접적 보조 측정값 및 추세 |
| 혈당 | `bloodglucose` | 혈당 추정의 직접적 보조 측정값 및 추세 |
| 체중·체성분 | `body_info`, `bodyfat` | 체중, BMI, 체지방, 골격근량, 복부·내장지방 관련 지표 |
| 수면 | `sleep`, `sleep_detail` | 수면시간, 단계, 효율, 규칙성, 각성 관련 특징 |
| 산소포화도 | `oxygen_saturation` | 야간 산소 상태·수면 관련 보조 지표 |
| 식사·영양 | `food`, `meal` | 식사 시간·패턴, 영양 기록이 있는 경우 영양 특징 |
| 기분 | `mood` | 생활습관·주관적 상태의 보조 지표 |
| 악력 | `grip_strength` | 근력 및 체성분·노쇠 관련 보조 지표 |

각 원천은 관측 빈도, 시작일, 결측률, 기기·앱 출처가 사용자별로 다르다. 따라서 “테이블이 존재한다”는 사실만으로 모델 입력 가능을 보장하지 않으며, 사용자·기간·항목별 품질 기준을 적용해야 한다.

## 7. 우선 예측 대상과 타당성

예측은 생리적 관련성, 현 데이터의 직접성, 실제 정답 데이터의 수량을 함께 고려하여 우선순위를 정한다. 아래는 **현재 데이터로 검토 가치가 있는 후보**이며, 예측 성능이 입증되었다는 뜻은 아니다.

| 우선순위 | 건강검진 항목 또는 군 | 활용 가능한 주요 웨어러블 근거 | 판단 |
|---|---|---|---|
| 높음 | 체중, BMI, 체지방률·체지방량, 골격근량 | `body_info`, `bodyfat`, 활동·칼로리 | 직접 또는 매우 근접한 측정값이 있어 가장 현실적 |
| 높음 | 수축기·이완기 혈압 | `bloodpressure`, 심박, 활동, 수면, 체성분 | 직접 혈압 기록이 충분한 사용자에서 우선 검토 |
| 중간 | 공복혈당·당대사 위험 신호 | `bloodglucose`, 식사, 활동, 수면, 체성분 | 측정 조건·식사 시점 정보가 중요하며 공복혈당과 구분 필요 |
| 중간 | 허리둘레·복부비만 관련 지표 | 체성분의 복부·내장지방 관련 값, 체중, 활동 | 직접 허리둘레가 없는 경우 간접 추정으로 한계를 명시 |
| 탐색 | 중성지방, HDL, LDL, 총콜레스테롤 | 체성분, 활동, 수면, 식사 기록 | 생활습관 연관성은 있으나 개인 단독 예측의 불확실성이 큼 |
| 탐색 | 간기능(AST, ALT, γ-GTP) | 체성분, 활동, 수면, 식사 | 현재 데이터만으로는 직접 생체신호가 부족해 검증 후 제한적으로 제공 |
| 제한적 | 혈색소, 크레아티닌, eGFR, 요단백 | 활동·체성분·수면의 비특이적 신호 | 직접적 근거가 약하므로 현 데이터만으로는 예측 우선순위가 낮음 |

혈압·혈당·체성분은 웨어러블 또는 연결기기가 제공하는 **측정값**과 건강검진의 **임상 측정값**이 완전히 같지 않을 수 있다. 원천, 단위, 측정 조건, 기기 검증 여부를 구분하고, 웨어러블 측정값을 건강검진 실제값으로 바꿔 표기해서는 안 된다.

## 8. 결과물의 모습

최종 결과는 사용자 1명당 1행의 CSV 또는 Excel 형태를 기본으로 한다. 예측 항목마다 다음 정보를 명확히 나눈다.

- 가장 최근의 실제 건강검진값과 `measuredDt` (존재할 때만)
- 웨어러블 기반 예측값과 예측 기준일
- 예측 구간 또는 신뢰도 등급
- 사용한 웨어러블 관측 기간·유효 일수·주요 입력 영역
- 예측 제공/보류 상태와 사유
- 과거 실제값이 있을 경우 실제값 대비 변화량

표시 예시는 `glucose_actual_latest`, `glucose_actual_measured_dt`, `glucose_predicted`, `glucose_prediction_interval`, `glucose_prediction_status`와 같다. 실제값, 기기 측정값, 모델 예측값은 별도 열로 절대 혼합하지 않는다.

## 9. 모델이 정당하려면 반드시 지켜야 할 조건

- **시간 방향성**: 각 건강검진 정답값을 예측할 때 그 검진의 `measuredDt` 이후에 생성된 웨어러블 데이터는 입력에 사용하지 않는다. 이는 미래 정보를 미리 보는 시간 누출을 막기 위한 조건이다.
- **사용자 단위 분리**: 같은 사용자의 기록이 학습과 평가에 함께 들어가면 성능이 과대평가될 수 있으므로, 사용자를 기준으로 학습·검증·시험 집단을 분리한다.
- **측정 조건 표준화**: 혈당의 공복 여부, 혈압의 측정 환경, 체성분 기기 차이 등은 별도 변수 또는 품질 기준으로 관리한다.
- **불확실성 공개**: 평균 오차만 제시하지 말고 항목별 오차, 예측구간, 데이터 충분성별 성능, 실제값 대비 그래프를 함께 평가한다.
- **임상적 위치의 제한**: 이 모델은 선별·추적을 지원하는 예측 모델이며, 진단·치료 결정 또는 건강검진의 대체 수단으로 표현하지 않는다.

## 10. 향후 수집되면 모델을 크게 고도화할 데이터

현재 데이터로도 체성분·혈압·혈당 관련 후보를 우선 검토할 수 있지만, 혈액검사 항목과 개인별 예측을 안정화하려면 다음이 특히 중요하다.

| 추가 데이터 | 기대 효과 |
|---|---|
| 웨어러블 측정의 원천·기기 모델·측정 조건·품질 플래그 | 동일한 수치라도 신뢰 가능한 입력만 선택하고 기기 차이를 보정 |
| 연속적 또는 식전·식후 구분 혈당, 식사 시각·영양성분 | 공복혈당·당대사 관련 추정의 정확도 향상 |
| 규칙적으로 수집된 가정혈압과 측정 자세·시간 | 건강검진 혈압과의 차이를 보정하고 개인별 추세 강화 |
| 체성분의 원시값·측정 조건·기기 정보 | 비만·근육량·복부비만 관련 예측의 일관성 향상 |
| 심박변이도(HRV), VO₂max, 운동 세션·강도·GPS 기반 운동 정보 | 심폐 체력 및 생활습관 특징을 강화 |
| 수면무호흡·수면 점수·피부온도·스트레스·에너지/준비도 | 수면·회복·대사 위험 관련 특징을 강화 |
| 흡연, 음주, 약물, 진단력, 가족력, 성별·연령, 임신 여부 | 혈액검사·혈압·간기능의 중요한 교란 요인을 보정 |
| 동일 사용자의 반복 건강검진과 검진 기관·장비·검사 조건 | 개인화 변화량 학습, 기관 간 차이 보정, 장기 검증 |

Samsung Health Data SDK에서 취득 가능성이 있는 심방세동, 수면무호흡, VO₂max, 운동 세션·경로, 영양·수분, 에너지/준비도 등의 항목도 수집 권한·사용자 동의·실제 적재 여부가 확인되면 우선적으로 연계 검토할 수 있다.

## 11. AI 협업 시 유지할 원칙

- `disc_medical_user_info.user_health_sn.health_info_data`를 건강검진 정답 원천으로 사용한다. 다른 건강검진 원천과 비교·혼합하지 않는다.
- 웨어러블 데이터가 건강검진 이후에 존재하면, 그 데이터는 **이후 시점의 최신 상태 추정**에는 사용할 수 있지만 과거 검진값을 맞히는 입력으로 사용하면 안 된다.
- ‘예측 가능 후보’, ‘예측 모델 성능이 검증됨’, ‘실제 임상값’은 서로 다른 주장이다. 성능 검증 전에는 후보를 확정 결과처럼 표현하지 않는다.
- 데이터가 부족하거나 측정 품질이 낮은 사용자는 예측을 강행하지 않고 보류해야 한다.
- 원본 개인식별정보, DB 비밀번호, 접속 문자열, 원시 건강 데이터를 외부 AI 대화에 넣지 않는다.

## 12. 현재 상태와 다음 의사결정

현재는 데이터 자산과 예측 타당성을 정리하는 단계다. 실제 모델의 알고리즘, 특징 산출 기간, 최소 관측일, 성능 기준은 데이터 품질 점검과 독립 검증 결과를 바탕으로 결정·수정한다.

우선 의사결정은 다음 두 가지다.

1. 현재 보유 데이터로는 체성분·혈압·혈당 관련 후보부터 타당성을 검증한다.
2. 혈액검사 전반을 신뢰성 있게 다루려면 반복 건강검진, 측정 조건, 생활습관·임상 공변량, 고품질 웨어러블 원천 메타데이터를 단계적으로 확보한다.

이 프로젝트의 성공 기준은 많은 항목을 무조건 출력하는 것이 아니라, 각 항목에 대해 **실제로 검증된 수준에서만 예측을 제공하고, 근거가 약하면 명확히 보류하는 것**이다.
