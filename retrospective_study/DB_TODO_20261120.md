# DB 작업 기록 (2026-11-20 진행)

DB 접속 없이 할 수 있는 작업은 2026-11-19에 끝냈고, 아래 DB 작업은 2026-11-20에 진행했습니다. 결과 숫자와 계정 점검 결과는 각 연구의 `docs/local/`(git 제외)에 있습니다. 전체 요약은 `00_common/docs/local/DB_작업결과_20261120.md`입니다.

## 지킬 것

- 모든 질의는 `00_common/src/db_query.sh`로만 실행합니다(읽기 전용 트랜잭션, `default_transaction_read_only=on`, 접속 전 문장 검사). 스키마·테이블 생성 같은 변경 작업은 하지 않습니다.
- 접속 계정은 읽기 전용(SELECT만 가능) 역할을 쓰는 것이 원칙입니다. 0단계 점검에서 쓰기 가능성이 보이면 추출 전에 멈추고 책임자 결정을 받습니다. 읽기 전용 계정을 요청하거나, 확인을 받아 이 도구로 조회만 합니다.
- 새 추출은 `00_Data/extract_YYYYMMDD/`처럼 날짜가 붙은 폴더에 둡니다. `run_extract.py`는 이미 있는 파일에 쓰지 않습니다.
- 추출문은 실행 전에 해당 `sql/` 파일에 `-- @extract <이름>` 블록으로 적어 둡니다.
- **인원·건수 같은 결과 숫자는 `docs/local/` 또는 `01_Results/`에만 적습니다.** git에 올라가는 README·md·SQL·코드에는 적지 않습니다.

## 0. 도구 확인

```bash
export RETRO_DB_ENV=<로컬 env 파일 경로>   # DB_HOST, DB_PORT, DB_NAME, DB_USER(또는 DB_USERNAME), DB_PASSWORD
cd retrospective_study
00_common/src/db_query.sh "show default_transaction_read_only"   # on 이어야 함
00_common/src/db_query.sh "copy (select 1 a, 2 b) to stdout csv header" > /tmp/retro_check.csv && cat /tmp/retro_check.csv
```

- 두 번째 결과는 `a,b`와 `1,2` 두 줄이어야 합니다. `BEGIN`, `ROLLBACK`, `COPY 1` 같은 줄이 섞이면 추출 파일이 깨지므로, 고친 뒤에 진행합니다.
- **계정이 읽기 전용인지는 DBA(DevOps)의 확인으로 정합니다.** 아래 질의는 보조 점검일 뿐이고, 모두 0·false여도 직접 부여·상속·소유 권한까지 다 보여 주지는 않습니다.

```bash
00_common/src/db_query.sh "select r.rolsuper, r.rolcreaterole, r.rolcreatedb, r.rolbypassrls, pg_has_role(current_user, 'pg_write_all_data', 'member') write_all from pg_roles r where r.rolname = current_user"
00_common/src/db_query.sh "select count(*) dml_grants from information_schema.role_table_grants where grantee in (select rolname from pg_roles where pg_has_role(current_user, oid, 'member')) and privilege_type in ('INSERT','UPDATE','DELETE','TRUNCATE')"
00_common/src/db_query.sh "select count(*) owned_relations from pg_class c where pg_has_role(current_user, c.relowner, 'member')"
00_common/src/db_query.sh "select n.nspname, has_schema_privilege(current_user, n.oid, 'CREATE') can_create from pg_namespace n where n.nspname in ('public','discovery','ichms','irs')"
```

- 2026-11-20: 도구 확인 두 가지는 통과했습니다. 계정 점검 결과와 진행 결정은 `00_common/docs/local/db_step0_20261120.md`에 있습니다.
