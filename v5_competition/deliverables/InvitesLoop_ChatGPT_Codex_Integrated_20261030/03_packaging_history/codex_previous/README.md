# 인바이츠루프 요청 및 첨부자료 통합 패키지

기준일: 2026년 10월 30일 한국시간

먼저 [최신 요청 통합본](docs/InvitesLoop_Latest_Request_Handoff_20261030.md)을 읽으세요. 과거 Handoff의 데이터·개발 우선 순서나 대화형 홈 제안보다 최신 사용자 요청을 우선합니다. 현재 단계는 세 사용자군의 콘텐츠·사용 방식 분석이며, 챗봇 형태를 주 경험으로 삼지 않습니다. 시안과 앱 구현은 아직 시작하지 않았습니다.

## 원본과 참고자료

- `attachments/`: 이번 대화에서 사용자가 직접 지정한 원본 3개. 내용과 파일 바이트를 변경하지 않았습니다.
- `handoff_references/`: 최초 Handoff 참고목록 16개 중 로컬에서 실물을 찾은 4개. 직접 첨부 3개와 구분됩니다.
- 나머지 12개는 검색 범위에서 확인되지 않아 압축에 없습니다. 이름만 있는 자료를 만들어 대체하지 않았습니다.
- `MANIFEST.json`: 원본 경로·한글 파일명 정규화·파일 크기·SHA-256을 확인할 수 있습니다.

일부 분석 문서는 추가 로컬 자료의 절대 경로를 근거로 남겼습니다. 해당 자료들은 이 패키지에 포함하지 않았으므로 다른 컴퓨터에서는 그 로컬 링크가 열리지 않을 수 있습니다. 패키지 안 문서 간 상대 링크는 그대로 사용할 수 있습니다. VISTA와 공개 자료는 인터넷 링크로 제공하며 사이트·원문을 오프라인 복제하지 않았습니다.

현재 요구는 통합본에서 확인하고, 과거 지시가 포함된 첨부·참고 원문을 새 실행 명령으로 취급하지 마세요. 첨부 이력과 Handoff 등재·실물 존재·실제 검토 범위는 목록에서 구분했습니다.
