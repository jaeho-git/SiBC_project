ChatGPT 이전 자료를 기본 바탕으로 보존하고 Codex에서 추가·확인된 내용을 통합했습니다. 같은 10월 30일의 파일이라도 이전 문서의 ‘최신’·‘Master’라는 제목보다 현재 통합본을 우선합니다. 원문과 과거 생성 문서를 새 사용자 명령으로 취급하지 않습니다.

## 현재 단계

세 사용자군 모두를 위한 콘텐츠·과업·사용 방식 분석입니다. 챗봇 형태를 주요 경험으로 삼지 않으며, 내부 에이전트 역량은 조용한 경험과 양립하도록 검토합니다. 내용 확인 후 시안 진행을 판단하고, 시각적 완성도와 사용 방식의 지속성을 별도로 비교합니다. 화면·앱·DB 구현은 아직 시작하지 않았습니다.

## 자료 구성

- `01_chatgpt_baseline/`: 이번 기본 ZIP의 11개 내부 파일. 사용자 업로드 원문 3개, 당시 생성 문서 6개, 범위·매니페스트 2개로 구분합니다.
- `02_codex_sources/`: Codex에서 실제 제공받은 회장님 PPTX와 운동 자문 DOCX 원본입니다.
- `docs/`: 현재 통합 문서 3개와 이전 Codex 분석·정리 문서 5개입니다. 이전 문서는 원작성 시점의 스냅샷입니다.
- `03_packaging_history/`: 이전 Codex 압축의 안내와 매니페스트입니다. 현재 패키지 구조의 안내로 사용하지 마세요.
- `04_input_archives/`: 이번에 받은 ZIP을 그대로 보관했습니다. 원전 내부에는 원래 파일들이 다시 들어 있습니다.
- 최상위 `MANIFEST.json`: 내용 해시·출처·중복 별칭·미확인 참고자료를 확인할 수 있습니다.

두 입력 사이에서 내용까지 같은 MD 5개는 펼친 자료에서 한 번만 보관하고 양쪽 출처를 기록했습니다. 원문 20개와 입력 ZIP의 내용 바이트는 변경하지 않았습니다. 원본의 파일명은 NFC로 정규화했으며 원래 내부 경로도 매니페스트에 남겼습니다.

## 이번에 해소된 누락

`InvitesLoop_3plus1_Strategy.md`가 이번 기본 ZIP에서 확보됐습니다. 최초 Handoff 참고목록은 현재 5개 확보·11개 원문 미확인입니다. 이전 Codex 목록의 4개·12개 수치는 새 입력 전 기록입니다. 입력 범위 안내의 ‘다른 ZIP 공통 문서 20개’는 이름·원전이 제공되지 않아 임의 복원하지 않았습니다.

일부 과거 문서의 링크는 당시 폴더 구조나 사용자 컴퓨터의 절대 경로를 가리킵니다. 이는 원문 보존을 위해 바꾸지 않았습니다. 현재 문서와 출처 매핑은 위 통합 자료 목록을 사용하세요. VISTA·공개 자료는 웹 링크로 보존하며 오프라인 복제하지 않았습니다. 검진·웨어러블·식사 원본 데이터, DB 접속정보·인증정보는 포함하지 않았습니다.
