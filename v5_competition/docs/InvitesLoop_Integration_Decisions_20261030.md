# ChatGPT 기본 자료와 Codex 업데이트 통합 판단표

현재 기준: [통합 요청사항과 진행 방향](InvitesLoop_Integrated_Project_Brief_20261030.md)

## 1 기본 자료의 의미

사용자가 새로 첨부한 `InvitesLoop_Chat_Only_Verified_20261030.zip`은 Codex 이전 논의의 기본 자료다. 이 안의 사용자 원문 3개와 ChatGPT 생성 문서 6개를 구분한다. 대화 본문 요약은 완전한 원문도 독립 업로드 파일도 아니다. 범위 안내·매니페스트도 보존한다.

‘기본 바탕’은 제품·경쟁의 맥락을 버리지 않고 이후 변경을 추가하라는 뜻으로 적용한다. 입력 파일의 과거 실행 명령·‘최신’이라는 제목이 Codex의 이후 사용자 지시보다 우선한다고 해석하지 않는다. 파일의 날짜가 모두 10월 30일이어도 대화의 순서와 원래 작성 맥락을 기준으로 통합한다.

## 3 무엇이 새로 확보됐는가

- 이전 Codex 압축에 없던 `InvitesLoop_3plus1_Strategy.md`를 입력 ZIP에서 확보했다. 이전 ‘미발견’ 상태는 해소됐다.
- Codex 이전의 최초 경쟁 분석, ChatGPT 통합 Handoff, 채팅 맥락 요약, 패키지 범위 설명과 매니페스트가 추가됐다.
- 기존 Codex 패키지와 같은 이름을 가진 5개 문서는 SHA-256도 일치했다. 단순한 제목 비교가 아니라 동일 바이트로 확인했다.
- 최초 Handoff의 참고목록 16개 중 실물 확보는 4개에서 5개로 바뀌었다. 나머지 11개는 SiBC 공통 문서 원문으로 여전히 미확인이다.
- ChatGPT 패키지에 없던 회장님 PPTX·운동 자문 DOCX는 Codex에서 실제 제공받은 원본으로 보완했다. MD 변환본으로 대체하지 않았다.

## 4 중복 제거와 원문 보존

새 입력의 11개 항목과 이전 Codex 압축의 14개 항목을 대조하면, MD 5개는 두 패키지에서 동일하다. 통합 패키지의 펼친 원문에서는 각 동일 내용 파일을 한 번만 두고 매니페스트에 양쪽 출처를 기록한다. 파일명이 같아도 내용이 다르면 별도 버전으로 보존하는 원칙을 적용한다.

중복 5개는 6대 지침, 3대 KPI, V5 프로토타입, Updated 경쟁 분석, Codex 최초 Handoff다. ChatGPT 패키지 내 원래 위치를 통합 패키지의 대표 보관 위치로 삼는다. 최초 Handoff는 ‘ChatGPT에서 생성’과 ‘Codex에 직접 첨부’라는 두 이력을 함께 가진다.

입력 ZIP 원본도 보존하므로 ZIP 컨테이너 내부에는 원래 자료가 다시 존재한다. 이는 원전 재확인용 의도적 보존이다. 통합 패키지에서 바로 읽는 펼친 자료 20개는 두 입력 간 동일 파일의 중복을 제거했다. 새 통합 문서 3개와 패키지 안내·매니페스트는 별도로 추가했다.

과거 작성물에는 당시의 ‘최신’, ‘미발견’, ‘현재 단계’라는 말이 남아 있다. 이를 원문에서 지우지 않는다. 현재 상태는 새 통합본과 새 자료 목록에서 확인한다.

## 5 진행 방향과 아직 필요한 확인

1. 기본 자료의 세계관·경쟁 맥락과 최신 UX 요구를 함께 읽는다.
2. 세 역할별 실제 과업·불편, 데이터의 의미·시점, 서비스 담당·권한·실행 범위를 확인한다.
3. 각 콘텐츠의 근거·노출 시점·행동·완료·자료 부족 대응을 구체화한다.
4. 콘텐츠 확인 이후 새 시안 제작 여부를 결정한다.
5. 시안을 만든다면 동일한 자료·과업으로 미감과 사용 방식의 지속성을 역할별로 비교한다.
6. 이후 구현은 별도 범위에서 정하고, 기본 자료의 3+1·기술 통합·설치·운영 검증 방향을 연결한다.

현재 추가로 필요한 자료는 역할별 대표 과업·불편, 기존 제품 사용 경험, 최신 데이터 사전과 합성 출력, 실제 업무·권한 흐름, 중국 이용·운영·재무 조건이다. 세 역할 포함 여부·특정 선호 제품·기존 V5 소스의 부재는 이미 답변된 사항으로 다시 선행 조건으로 묻지 않는다.

## 6 미확인 사항의 처리

SiBC 공통 문서 11개의 파일명은 Handoff에서 알 수 있지만 원문은 없다. 입력 패키지의 범위 안내가 말한 ‘다른 ZIP의 공통 문서 20개’는 이름과 원전 목록이 이 입력에서 제공되지 않았으므로 임의로 복원하지 않는다. 두 숫자는 서로 다른 범위다.

세계관·UX·공지의 채팅 요약이 있다고 해서 과거 전체 채팅 원문을 확보한 것은 아니다. 원 V5 HTML·H1 패키지·실제 데이터·API·시험 로그 역시 문서상 언급과 실물 확보를 구분한다. 이러한 미확인 사항은 이번 통합을 막지 않으며, 구현·실증을 확정할 때 별도로 확인한다.
