# 인바이츠루프 UX UI 시안 비교 기준

작성일: 2026년 10월 29일 한국시간  
상태: 향후 시안 평가를 위한 제안. 아직 시안·사용자 시험·평가 점수 없음.  
관련 문서: [콘텐츠 분석 개정안](UX_UI_Content_Strategy_v2_20261029.md)

최신 확인 사항: 세 사용자군은 모두 필수 평가 대상이다. 챗봇 형태에서 벗어나야 한다는 사용자 확인을 적용한다. 채팅창·말풍선·대화 이력을 주요 화면과 업무의 중심으로 둔 안은 후보에서 제외한다. 자연어는 보조 입력으로만 검토한다. 특정 외부 제품을 선호한다는 근거는 없다.

## 1 비교 목적

‘Agentic한 인상이 적다’와 ‘미래에도 낡아 보이지 않는 경험’을 별도로 확인한다. 시각적 완성도와 사용 방식의 지속성을 하나의 인상 점수로 합치지 않는다. 세련된 외형이 낮은 사용성·불명확한 승인·안전 문제를 상쇄할 수 없다.

장기 지속성은 현재 시점에서의 설계 가설이다. 기능·상황·기기가 달라지는 과업을 통해 변화 대응 능력을 검토할 수 있지만 미래의 미적 선호를 입증할 수는 없다.

## 2 이후 검토할 수 있는 방향

아래는 비교를 위한 구조적 가설이다. 화면을 제작하거나 우승안을 정한 상태가 아니다. 콘텐츠 확인 후 최소 두 방향을 선택해 같은 범위로 비교하는 방안을 제안한다. 계획·근거·상태는 모두에서 확인 가능해야 한다. 보조 자연어 입력은 사용할 수 있지만 그 사용을 필수로 만들지 않는다.

| 방향 | 우선하는 경험 | 기대하는 장점 | 확인할 위험 |
|---|---|---|---|
| A 상황과 다음 행동 중심 | 현재 상태와 필요한 행동에서 시작하고 필요할 때 상황을 보충 | 시작 부담과 탐색 감소 | 전체 계획·이력·근거를 찾기 어려워질 수 있음 |
| B 개인의 변화와 경과 중심 | 이전 맥락과 달라진 점을 이해하고 다음 선택으로 연결 | iSignature·iPresent·iFuture와 여정의 연속성 | 경과 정보가 많아 즉시 행동이 늦어질 수 있음 |
| C 공유 계획과 진행 중심 | 현재 계획·담당·다음 확인을 중심으로 연결 | 의료진 협업과 수행 상태의 명확성 | 일반사용자에게 업무 관리 도구처럼 느껴질 수 있음 |

세 역할을 같은 화면으로 통일하지 않는다. 각 방향의 우선순위를 역할에 맞게 표현한다. A에서 의료진은 오늘 검토할 변화, 재무담당자는 실적 예외에서 시작할 수 있다. B에서 의료진은 진료 이후 경과, 재무담당자는 기간별 변동 원인을 다룰 수 있다. C에서 의료진은 관리계획·조치, 재무담당자는 서비스 진행과 정산을 중심으로 볼 수 있다. 이는 구체적인 레이아웃 확정이 아니다.

## 3 비교 조건

- 동일한 합성 페르소나·관찰·계획·기관·기간과 정보량으로 비교한다.
- 기능 범위와 상호작용 완성도를 맞춘다. 정적 그림과 작동하는 프로토타입의 과업 점수를 직접 비교하지 않는다.
- 미감 비교에서는 색상·서체·여백 등의 차이를 평가하고, 사용성 비교에서는 과업을 평가한다. 역할별 결과를 따로 기록한다.
- 동일 문구가 가능한 곳은 유지한다. 설명량이 다르면 차이와 이유를 기록한다.
- 사용 순서를 교차해 학습 효과를 줄인다. 진행자의 설명·힌트는 동일하게 관리한다.
- 시험 인원·환경·숙련도·보조 입력·도움 여부를 기록한다. 작은 탐색 시험을 모집단 수용성 검증으로 제시하지 않는다.

## 4 시각적 완성도

각 항목은 1~5점의 검토 척도를 제안한다. 점수는 평가자별로 보존하고 이유와 화면 근거를 기록한다. 아직 가중치·통과점수는 정하지 않는다.

| 항목 | 확인할 내용 |
|---|---|
| 정보 위계 | 현재 상황·주요 행동·상태가 먼저 이해되는가 |
| 글자와 읽기 | 크기·대비·줄길이·다국어에서 읽기 쉬운가 |
| 밀도와 여백 | 중요한 정보가 묻히거나 불필요하게 분산되지 않는가 |
| 제품의 정체성 | 개인의 맥락과 건강 여정이 느껴지고 타 AI 제품의 장식에 의존하지 않는가 |
| 상태 표현 | 검토·승인·완료·자료 부족을 색 외의 표현으로도 구분하는가 |
| 움직임 | 변화·처리 결과 이해를 돕고 집중을 방해하지 않는가. 움직임 감소 환경도 고려하는가 |
| 크기와 언어 적응 | 확대·작은 화면·긴 번역에서도 우선순위와 조작이 유지되는가 |

선호 색상이나 화려함을 미래 지속성의 대리 지표로 쓰지 않는다. 익숙한 표·버튼도 맥락과 목적에 적절하면 유지할 수 있다. 접근성 검토를 미적 선호 평가로 대체하지 않는다.

## 5 사용 방식의 지속성

| 항목 | 확인할 내용 | 기록할 관찰 |
|---|---|---|
| 시작과 재진입 | 매번 질문을 만들거나 과거를 다시 설명하지 않아도 되는가 | 재입력 내용·힌트·시작 지연 |
| 정보의 지속성 | 결정·계획·결과를 대화 밖에서도 다시 찾는가 | 찾기 성공·시간·오해 |
| 상황 적응 | 필요한 내용이 달라져도 핵심 조작을 찾는가 | 재탐색·잘못된 선택 |
| 안정적인 통제 | 승인·변경·도움·거절의 의미가 일관적인가 | 상태 혼동·의도치 않은 실행 |
| 입력 부담 | 짧은 응답과 적법한 재사용으로 부담을 줄이는가 | 필수 입력 수·누락·중단 이유 |
| 여정 연속성 | 진료·퇴원 이후 새 관리주기에 맥락을 이어받는가 | 최신 계획 식별·불필요한 재설명 |
| 기능 확장 | 새 서비스가 추가돼도 기존 과업을 유지하는가 | 기존 경로 변경·새로운 학습 |
| 기기와 채널 | 다른 기기·입력 방식에서도 업무를 이어가는가 | 상태 유실·중복 입력·핵심 기능 접근 |
| 실패와 사람 연결 | AI 오류·자료 부족·연결 실패 후 진행할 수 있는가 | 오류 인지·수정·담당 연결 |

단순한 클릭 수 감소는 성공이 아니다. 승인 생략이나 근거 미확인으로 줄어든 단계는 이점으로 세지 않는다. 응답하지 않은 주관적 상태를 자동 측정이나 정상값으로 간주하지 않는다.

## 6 역할별 동일 과업

| ID | 역할과 상황 | 확인할 과업 | 비교 근거 |
|---|---|---|---|
| U1 | 일반사용자, 일상 재진입 | 현재 유효한 계획과 다음 행동 확인 | 정확한 내용·승인 상태·찾기 시간 |
| U2 | 일반사용자, 일정 제약 | 어려움 전달 후 일정 변경 요청과 처리 상태 확인 | 반복 입력·임상 변경 오인 여부 |
| U3 | 일반사용자, 운동 후 | 체감·통증·회복 등 필요한 반응 전달과 후속 상태 확인 | 부담·표현 이해·사람 연결 가능성 |
| U4 | 일반사용자, 진료 후 | 바뀐 사실·계획·이유와 다음 확인 파악 | 이전 계획 혼동·맥락 승계 |

| C2 | 의료진, 계획 변경 | 독립적으로 수정·승인·보류하고 적용 내용 확인 | 상태 구분·변경 전후 정합성 |
| C3 | 의료진·사례관리, 후속 지연 | 미완료 이유·담당·다음 조치 파악 | 긴급성과 연락 필요의 혼동 여부 |
| F1 | 재무담당, 실적 검토 | 기관·기간·자료 상태와 차이의 원인 확인 | 실적·미수신·0 구분과 단위 이해 |
| F2 | 재무담당, 시나리오 | 하나의 가정을 변경하고 기준안과 비교 | 가정·관찰 실적·귀속효과 구분 |
| F3 | 재무담당, 운영 검토 | 서비스 매출과 관리 인력·시간·비용 연결 | 누락 원가·중복 효과·개인정보 과노출 |

경과·미방문·연결 실패는 합성 시나리오로 구성하고 실제 환자 정보는 사용하지 않는다. 임상적 정답을 UX 시안으로 검증하지 않는다. 정적 시안은 이해도·선호·탐색 경로만 평가하고 실제 실행 성공률·완료 시간 검증은 적절한 상호작용 구현 이후에 한다.

## 7 변화 대응과 인상 확인

### 변화 대응 과업

1. 새 진료·검사·의약품 서비스가 추가됐을 때 기존 계획 확인 과업이 유지되는지 살핀다.
2. 시간이 지난 뒤 재방문한 합성 상황에서 이전 판단과 최신 계획을 구분하는지 확인한다. 실제 장기 사용성 검증과는 다르다.
3. 언어 변경·화면 확대·작은 화면에서 중요한 조작과 상태가 유지되는지 확인한다.
4. 관찰 누락·오래된 계획·연결 실패를 넣어 불확실성과 사람의 도움 경로를 확인한다.

### 인상 질문

다음은 평가 질문 제안이며 관찰을 대신하지 않는다. 먼저 자유 응답을 받고 같은 척도로 각 방향을 평가한다.

- 이 서비스를 어떤 일을 하는 제품으로 이해했는가?
- 내가 AI를 관리하거나 지휘해야 한다고 느꼈는가?
- 다음에 무엇을 해야 하는지, 무엇이 아직 결정되지 않았는지 알 수 있었는가?
- 익숙함·새로움·세련됨을 각각 어떻게 느꼈으며 어떤 요소 때문인가?
- 계속 이용할 때 부담스러울 부분은 무엇인가?

‘미래적이지요?’ 같은 유도 질문을 쓰지 않는다. 세 사용자군과 회장님의 제품 선호는 구분해서 기록한다. 한 집단의 선호를 다른 집단의 수용성으로 해석하지 않는다.

## 8 점수와 별도로 통과해야 할 사항

- AI 미확정 추론과 의사 확정, 초안과 적용 계획을 구분한다.
- 자료가 없거나 부적합할 때 허위 정상·개인 예측·실적을 생성하지 않는다.
- 합성·가정과 관찰 실적·검증된 효과를 구분한다.
- 환자·기관·역할·공유 권한을 혼동하지 않는다.
- 중요한 확인·승인·도움 경로에 접근할 수 있다.
- 전달·열람·수령을 실제 수행·복용·효과로 바꾸지 않는다.
- 웨어러블·건강검진·식이·루틴 정보의 관찰 기간과 수신 지연을 구분하고, 단순한 동시 변화로 인과를 단정하지 않는다.
- 루틴의 자기보고·행동 완료·생활패턴 인식·기기 관찰을 같은 사실로 합치지 않는다.
- 세 역할의 핵심 과업을 채팅 없이 완료할 수 있다. 자연어를 쓰지 않는 사용자의 경로도 확인한다.

중대한 오해나 권한·승인 문제가 있는 방향은 수정 후 재검토한다. 시각 점수와 평균을 내서 통과시키지 않는다.

최종 선택은 역할별 강점·문제와 상충관계를 함께 제시한다. 전체 평균으로 한 역할의 사용 불가를 가리지 않는다. 실제 비교 후 필요하면 방향을 결합하되, 결합안도 중요 과업을 다시 확인한다. 현재는 평가표만 작성했으며 실제 시안이나 검증 결과는 없다.
